# システム要件定義書：Personal English Companion

## 1. プロジェクト概要

日常の英会話を劇的に効率化し、自分の英語レベルに合わせた最適な表現を提示する個人専用のPWAツール。Gemini APIを活用し、通信量と手間の最小化を目指す。

## 2. 機能要件

### 2.1 翻訳・推敲エンジン（核心機能）

- **双方向翻訳**: 日本語 → 英語、英語 → 日本語の即時変換。
- **レベル別提案**:
  - 「現在の実力（即戦力表現）」：今すぐ口に出せる平易な英文。
  - 「ステップアップ（学習表現）」：少し背伸びしたネイティブに近い英文。
- **文脈指定**: シチュエーション（カフェ、授業、交渉、友人等）に応じたトーンの自動調整。

### 2.2 プロンプト・メモリ機能

- **パーソナリティ同期**: ユーザー名「Neo」としてのアイデンティティや、現在の学習状況をシステムプロンプトに常時組み込む。
- **レベル記憶**: 現在のCEFRレベルや苦手な表現をアプリ内に保持。

### 2.3 UI/UX

- **ワンタップ起動**: PWA化によりホーム画面から即座にアクセス。
- **チャット履歴の非保持（軽量化）**: 各リクエストをステートレスに処理し、ストレージ容量を節約。
- **プリセットボタン**: 「短く」「丁寧に」「スラングで」などの頻用指示をボタン化。

## 3. 非機能要件

### 3.1 データ通信の最適化

- **API通信の軽量化**: 余計なヘッダーやメタデータを削り、純粋なテキストデータのみを送受信。
- **静的資産のキャッシュ**: PWAのService Workerにより、アプリ本体のロードには通信を発生させない。

### 3.2 パフォーマンス

- **Zero-Latency UI**: 入力中に送信準備を完了させ、結果をストリーミングで表示（GeminiのStreaming APIを利用）。

## 4. 技術スタック（推奨）

| カテゴリ       | 技術                             | 選定理由                                                     |
| :------------- | :------------------------------- | :----------------------------------------------------------- |
| **Frontend**   | Next.js (App Router), TypeScript | 開発効率と、将来的な機能拡張（音声入力など）の容易さ。       |
| **Styling**    | Tailwind CSS                     | 軽量なCSSビルドと高速なUI構築。                              |
| **Deployment** | Vercel                           | サーバーレス環境（Edge Functions）によるグローバルな低遅延。 |
| **Storage**    | LocalStorage / IndexedDB         | ユーザー設定や英語レベルの保持（サーバー不要）。             |

## 5. プロンプト設計（System Instruction）

このツールの肝となる、APIに常に送信する指示セットの構成案です。

```markdown
# Role

Neo専用の英語メンター兼、通信量節約型の超高速翻訳機。

# Context

- ユーザー名: Neo
- 現在の英語レベル: Intermediate (CEFR B1-B2程度)
- 滞在環境: セブ島（フィリピン）→ バンクーバー（カナダ）予定
- 目標: 自然でスマートな表現を身につけつつ、現場で詰まらないこと。

# Rules

1. 挨拶や「もちろんです」といった不要な装飾語は一切排除し、結果のみを返す。
2. 入力が日本語の場合、[Quick Response] と [Advanced Expression] の2つを提示する。
3. [Quick Response] は、Neoが今すぐ正確に発音・理解できる構文（SVO中心）にする。
4. [Advanced Expression] は、語彙を少し強化し、より洗練された自然な言い回しにする。
```
